# 待驗主張清冊

網站上有些判讀文案是「啟發式」：看起來合理，但從沒用歷史資料驗證過有沒有預測力。
這份清冊把每一條「網站暗示了什麼」登記下來，逐條回測，結案只有四種：

| 狀態 | 意義 |
|---|---|
| 待驗 | 已登記，還沒跑 |
| 確認 | 效果存在、方向與文案一致、統計上站得住腳 |
| 證偽 / 不顯著 | 看不出效果，或方向與文案相反 → 要改文案或加註 |
| 理由改寫 | 效果存在，但原本的解釋不對 → 保留功能、改寫說明 |

驗證原則（避免回測變成找參數）：門檻沿用網站現值**不調參**；只用 t 日以前的資料（無前視）；
與「同一檔股票無條件平均」比較超額報酬，不拿多頭漂移當訊號；統計用時間區塊平均吸收同日跨股票相關。
腳本放在 `scripts/claims/`，每條主張一支，可重跑。

## C1–C3 主力成本判讀（chip_cost.py）— 2026-10-09 驗證

- **C1** 乖離率 < -5% →「主力套牢」，文案暗示後續可能護盤（畫面用偏多色）。
- **C2** 乖離率 > +5% →「主力獲利」，文案暗示留意調節賣壓（畫面用偏空色）。
- **C3** 集中度 ≥ +3%「籌碼明顯流入」／≤ -3%「持續調節出貨」。

資料：台股 30 檔大型權值股、2022-01-01 → 2026-10-09、34,627 個股票日；腳本 `scripts/claims/validate_major_cost.py`。

| bucket | H（交易日） | 事件數 | 命中率 | 基準命中率 | 區塊超額報酬 | t（區塊） |
|---|---|---|---|---|---|---|
| C1 乖離<-5% | 5 / 10 / 20 | 8,409 / 8,394 / 8,352 | 52.2 / 54.6 / 54.8% | 51.4 / 53.2 / 54.1% | +0.22 / +0.48 / +0.73% | 1.15 / 1.31 / 0.94 |
| C2 乖離>+5% | 5 / 10 / 20 | 7,750 / 7,686 / 7,544 | 51.6 / 52.9 / 53.0% | 同上 | -0.31 / -0.44 / -0.84% | -1.29 / -1.04 / -1.02 |
| C3a 集中度≥+3% | 5 / 10 / 20 | 12,564 / 12,481 / 12,320 | 52.2 / 55.3 / 55.5% | 同上 | +0.11 / +0.18 / +0.25% | 0.72 / 0.57 / 0.38 |
| C3b 集中度≤-3% | 5 / 10 / 20 | 12,424 / 12,398 / 12,350 | 51.5 / 52.7 / 50.6% | 同上 | -0.11 / -0.22 / -0.60% | -0.80 / -0.82 / -1.05 |

**結論：全部不顯著（|t| < 2），C1、C2、C3 皆結案為「不顯著」。**

- 沒有任何一格達到 |t| ≥ 2。命中率與基準相差多在 1–2 個百分點內（差最多的是 C3b 的 20 日，低 3.5 個百分點）。
- 方向上 C1 偏正、C2 偏負（與文案一致），C3 流入偏正、流出偏負，但幅度小、不穩。
- 沒校正時（逐事件、不處理同日跨股票相關）C3 會出現 |t| 約 1.8–2.9 看似顯著；一做區塊平均就消失。
  這正是課程提醒的「重疊視窗與同日相關會灌水樣本」。
- 另一個不穩定的證據：C2 在「逐檔事件平均」是正超額（+0.05 → +0.55%）、在「時間區塊平均」是負超額，兩種算法符號相反。

**對網站的意涵**：「主力獲利，留意調節賣壓」「主力套牢，可能有護盤」是**敘事**，這份資料撐不起來。
建議（待決定）：在主力成本區加一行「此判讀為成本位置描述，歷史回測未顯示顯著預測力」，並避免用偏多／偏空顏色暗示方向。

**限制**：存活者偏差（只挑現在的大型股）、未還原收盤價、無交易成本、整段期間以多頭為主、區塊 t 值仍屬近似。
不代表在小型股或空頭環境同樣不顯著。
