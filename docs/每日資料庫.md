# 每日資料庫（白名單股票增量存進 MongoDB）

每個平日 15:00（台灣時間）自動把「白名單」裡的股票資料抓下來，存進 MongoDB。只抓新的，不整段重抓。

## 存什麼

| 資料集 | collection | 來源（FinMind） | 唯一鍵 | 第一次回補 |
|---|---|---|---|---|
| `price` 日 K | `md_price` | TaiwanStockPrice | symbol + date | 400 天 |
| `institutional` 三大法人 | `md_institutional` | TaiwanStockInstitutionalInvestorsBuySell | symbol + date + name | 180 天 |
| `margin` 融資融券 | `md_margin` | TaiwanStockMarginPurchaseShortSale | symbol + date | 180 天 |
| `valuation` 本益比／淨值比 | `md_valuation` | TaiwanStockPER | symbol + date | 400 天 |
| `revenue` 月營收 | `md_revenue` | TaiwanStockMonthRevenue | symbol + date | 800 天 |

另有 `md_state`（每檔股票、每個資料集存到哪一天）與 `md_runs`（最近 30 輪的執行紀錄）。

## 怎麼「增量」

- `md_state.last_date` 記每檔每個資料集存到哪天。下次從 `last_date` **往前重疊幾天**開始抓（日資料 3 天，吃掉盤後更正；月營收 45 天，因為公布有時間差），用唯一鍵 upsert，所以重疊的部分不會變成兩份。
- 第一次（沒有 `last_date`）才回補歷史。
- 假日／休市抓不到新資料：`last_date` 不動，下次照樣從舊的接續。
- FinMind 額度用完（HTTP 402／403／429）：這一輪立刻停止，已存的不受影響，下一輪接續。單一檔案、單一資料集出錯只記在 `last_error`，不影響其他。

## 白名單

存在 MongoDB（`settings` 集合，key `stock_store_whitelist`）。沒設定過才用環境變數 `STOCK_STORE_SYMBOLS`（逗號分隔）。代號 4～6 碼英數字，自動轉大寫、去重，**最多 100 檔**（免費額度每小時 600 次，每檔每輪最多 5 次呼叫）。

需要管理員 token（`X-Admin-Token`）：

```bash
# 設定白名單
curl -X PUT https://<host>/api/v1/store/whitelist -H "X-Admin-Token: <token>" \
  -H "Content-Type: application/json" -d '{"symbols":["2330","0050","2317"]}'

# 看白名單 / 狀態（每檔每個資料集存到哪天、各集合筆數、最近幾輪）
curl https://<host>/api/v1/store/whitelist -H "X-Admin-Token: <token>"
curl https://<host>/api/v1/store/status -H "X-Admin-Token: <token>"

# 馬上跑一輪（背景執行；不給 symbols 就用白名單，datasets 可只挑幾個）
curl -X POST https://<host>/api/v1/store/run -H "X-Admin-Token: <token>" \
  -H "Content-Type: application/json" -d '{"datasets":["price"]}'
```

讀已存資料（唯讀、不用登入、不打 FinMind）：`GET /api/v1/store/data/{dataset}/{symbol}?start=2026-01-01&end=2026-11-11&limit=500`（由舊到新）。

## 排程環境變數

| 變數 | 預設 | 說明 |
|---|---|---|
| `STOCK_STORE_ENABLED` | `true` | `false` 關閉自動排程（手動 `/run` 仍可用） |
| `STOCK_STORE_HOUR` / `STOCK_STORE_MINUTE` | `15` / `0` | 台灣時間，只在平日 |
| `STOCK_STORE_SYMBOLS` | 空 | 資料庫沒有白名單時的預設白名單 |

## 注意

- **15:00 抓得到當天資料嗎？** 各資料集在 FinMind 的更新時間不一定一樣（實測晚上 19 點時，日 K、法人、本益比已有當天資料，融資融券還停在前一天；15:00 當下的情況沒有實測）。因為是增量＋重疊，當天沒抓到的，隔天那一輪會補上。
- 這是**存資料**的機制，現有頁面還是各自抓 FinMind；之後可以逐步改成「先讀資料庫、沒有再抓」，降低 FinMind 額度壓力。
- 原有的「15:00 re-ingest 關聯圖／類股輪動」（`AUTO_INGEST_*`，存在 `raw_prices` 等集合）沒有改動，兩者互不影響。

程式：`backend/app/data/stock_store.py`、`backend/app/api/stock_store.py`、排程在 `backend/app/scheduler.py`；測試：`backend/tests/test_stock_store.py`、`e2e/tests/stock-store.spec.js`。
