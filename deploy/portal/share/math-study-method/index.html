1. 方法：照課本順序抄五種條目

讀每一章時，我照課本的順序，把下面五種條目一條一條抄到筆記本，並且弄清楚它們之間的關係。例題、說明文字、證明的細節先不抄。

種類代號它是什麼抄的時候要問自己
定義 DefinitionD規定一個名詞的意思，不需要證明。這個名詞要滿足哪幾個條件？
公設 AxiomA不證明、直接接受的出發點。整章有哪些結論最後都靠它？
定理 TheoremT證明出來的主要結論。條件有幾個？結果有幾個？證明用到前面哪幾條？
輔助定理 LemmaL為了證明某個定理，先證的小結果。它是為了哪一個定理準備的？
推論 CorollaryC從定理直接得到的結果。它是哪一個定理的推論？

每一條給一個代號：種類的字母加流水號，例如 D1、T3、C2。之後寫「用到 T3」就不用把整條定理再抄一次。

照課本順序抄有一個好處：課本的順序本身就是邏輯順序，後面的條目只會用到前面的。抄完一章，關聯圖幾乎已經在筆記裡了。

2. 把文字改寫成簡式

課本敘述定義和定理時文字很多。我抄的時候改用固定的幾個符號，句型就只剩下「if … then …」和「… iff …」兩種，容易讀也容易背。

若且唯若、充要條件iff存在\(\exists\)
且、並且、同時&使得s.t.

以均值定理為例，左邊是課本的寫法，右邊是筆記上的寫法：

課本的寫法
設函數 f 在閉區間 [a, b] 上連續，在開區間 (a, b) 內可微，則在 (a, b) 內至少存在一點 c，使得 f′(c) 等於 f(b) − f(a) 除以 b − a。
簡式
前提\(f: [a,b] \to \mathbb{R}\)

&2\(f\) diff. on \((a,b)\)
then\(\exists\, c \in (a,b)\) s.t.
a\(f'(c) = \dfrac{f(b)-f(a)}{b-a}\)

右邊一眼就看得出結構：兩個條件、一個結果。左邊要讀完整句才知道。

3. 給條件和結果編號

一條定理常常有好幾個條件、好幾個結果。我的做法：

  • 條件用數字 1 2 3 編號，每個條件寫一行。
  • 結果用英文字母 a b c 編號，每個結果寫一行。
  • 行首寫 & 或 or，表示這一行和上一行的關係。
  • 量詞（\(\forall\)、\(\exists\)）和背景設定不編號：背景寫在最前面的「前提」，量詞寫在它管的那幾行前面。

這樣背的時候先背「骨架」：例如 Rolle 定理是「3 個條件、1 個結果」，均值定理是「2 個條件、1 個結果」，兩者只差條件 3。骨架記住了，再填內容。

考試時怎麼用

要用某個定理之前，照編號一條一條打勾，全部成立才能寫下結果。例如想對 \(f(x) = |x|\) 在 \([-1, 1]\) 用均值定理：

條件檢查成立？
1 \(f\) conti. on \([-1,1]\)\(|x|\) 處處連續成立
2 \(f\) diff. on \((-1,1)\)\(|x|\) 在 \(x=0\) 不可微不成立

條件 2 不成立，所以不能用。實際上結果也真的不對：\(\dfrac{f(1)-f(-1)}{1-(-1)} = 0\)，但 \(f'(x)\) 只會是 \(1\) 或 \(-1\)，找不到 \(c\)。沒有編號時，最容易漏掉的就是這種「看起來理所當然」的條件。

結果有編號也有用：題目要求證明某個定理時，寫完可以對照 a、b、c，確認每個結果都證到了。

4. 示範一：微積分「均值定理」

這一章從極值的定義開始，一路推到均值定理和它的應用。共 1 個定義、6 個定理、3 個推論。這一章沒有公設，也沒有課本標成 Lemma 的條目。

4.1 依課本順序的筆記

定義 Definition D1極大值與極小值Maximum & Minimum
前提\(f: D \to \mathbb{R},\ c \in D\)

iff\(\exists\, \delta \gt 0\) s.t.
1\((c-\delta,\ c+\delta) \subseteq D\)
&2\(f(x) \le f(c)\ \ \forall x \in (c-\delta,\ c+\delta)\)

極小值（min）：把 \(\le\) 換成 \(\ge\)。注意 local max 的條件 1 表示 \(c\) 不能是定義域的端點。

課本的寫法若定義域 D 中的每一個 x 都滿足 f(x) ≤ f(c)，則稱 f 在 c 有絕對極大值。若存在一個包含 c 的開區間，使得區間內的每一個 x 都滿足 f(x) ≤ f(c)，則稱 f 在 c 有局部極大值。

用到：T3
被用於：T6
定理 Theorem T6L'Hôpital 法則（0/0 型）L'Hôpital's Rule
前提\(I\) open interval, \(a \in I\)；\(f, g\) diff. on \(I \setminus \{a\}\)
if1\(\lim\limits_{x \to a} f(x) = 0\) & \(\lim\limits_{x \to a} g(x) = 0\)
&2\(g'(x) \ne 0\ \ \forall x \in I \setminus \{a\}\)
&3\(\lim\limits_{x \to a} \dfrac{f'(x)}{g'(x)} = L\)
thena\(\lim\limits_{x \to a} \dfrac{f(x)}{g(x)} = L\)

\(L\) 可以是實數，也可以是 \(\pm\infty\)。考試最常漏的是條件 1：沒先確認是 0/0 型就直接微分。

課本的寫法設 f 與 g 在包含 a 的開區間 I 上（a 點本身可以除外）可微，且 g′(x) ≠ 0。若 x 趨近 a 時 f(x) 與 g(x) 的極限都是 0，而且 f′(x)/g′(x) 的極限存在（或為正負無限大），則 f(x)/g(x) 的極限等於 f′(x)/g′(x) 的極限。
用到：T5

4.2 關聯心智圖

定義 Definition（D）公設 Axiom（A）定理 Theorem（T）輔助定理 Lemma（L）推論 Corollary（C）箭頭 A → B：證明 B 時用到 A。點方塊可跳到該條。

4.3 這張圖怎麼讀

  1. D1 → T1、T2：兩個定理講的都是極大值、極小值，要先有定義。
  2. T1、T2 → T3：T1 保證 \(f\) 在 \([a,b]\) 上有最大值和最小值。如果兩個都出現在端點，條件 3 \(f(a)=f(b)\) 讓 \(f\) 是常數，\(f'\) 處處為 0。否則至少一個出現在 \((a,b)\) 內，它也是局部極值，T2 給出 \(f'(c)=0\) or \(f'(c)\) 不存在；條件 2 排除了後者。
  3. T3 → T4：把 \(f\) 減掉通過兩端點的直線，令 \(h(x) = f(x) - f(a) - \dfrac{f(b)-f(a)}{b-a}(x-a)\)。\(h\) 滿足 Rolle 定理的條件 1、2、3，\(h'(c)=0\) 整理後就是 T4 的結果。
  4. T4 → C1、C3：在 \((a,b)\) 內任取 \(x_1 \lt x_2\)，對 \([x_1, x_2]\) 用 T4，得到 \(f(x_2) - f(x_1) = f'(c)(x_2 - x_1)\)。\(f'(c)=0\) 就得到 C1，\(f'(c) \gt 0\) 就得到 C3。
  5. C1 → C2：對 \(f - g\) 用 C1。
  6. T3 → T5：令 \(h(x) = [f(b)-f(a)]\,g(x) - [g(b)-g(a)]\,f(x)\)，可以算出 \(h(a) = h(b)\)，再用 Rolle 定理。
  7. T5 → T6：補上 \(f(a) = g(a) = 0\) 之後，對 \(a\) 和 \(x\) 之間的區間用 T5，得到 \(\dfrac{f(x)}{g(x)} = \dfrac{f'(c)}{g'(c)}\)，再讓 \(x \to a\)。
畫完圖可以看出三件事。第一，Rolle 定理（T3）是整章的樞紐：它名字叫定理，實際上扮演的是輔助定理的角色，T4 和 T5 都從它出來。第二，C1、C2、C3 都掛在 T4 底下，所以課本才叫它們推論。第三，指向 T1 的只有定義 D1，沒有任何定理：微積分課本直接接受它，真正的證明在下一章。

5. 示範二：高等微積分「實數的完備性」

高等微積分會把微積分裡「直接接受」的事實追到最源頭。這一章的源頭是一條公設，其他定理都從它推出來。共 5 個定義、1 個公設、6 個定理、3 個輔助定理、1 個推論。

5.1 依課本順序的筆記

定義 Definition D1上界與有上界Upper bound
前提\(S \subseteq \mathbb{R},\ S \ne \emptyset,\ u \in \mathbb{R}\)

iff\(\exists\, u \in \mathbb{R}\) s.t.

下界（lower bound）與有下界（bdd below）：把 \(\le\) 換成 \(\ge\)。

課本的寫法設 S 是實數的非空子集。若實數 u 滿足：S 中的每一個元素 s 都小於或等於 u，則稱 u 是 S 的一個上界。若 S 至少有一個上界，則稱 S 有上界。
被用於：D2
定義 Definition D2最小上界Supremum
前提\(S \subseteq \mathbb{R},\ S \ne \emptyset,\ u \in \mathbb{R}\)

&2if \(v\) is an upper bound of \(S\), then \(u \le v\)

最大下界 \(\inf S\) 的定義對稱：把上界換成下界、\(u \le v\) 換成 \(u \ge v\)。

課本的寫法若 u 是 S 的上界，而且 S 的任何一個上界 v 都滿足 u ≤ v，則稱 u 是 S 的最小上界，記為 sup S。
用到：D1
被用於：A1 L1

前提\(S \subseteq \mathbb{R}\)
if1\(S \ne \emptyset\)
&2\(S\) is bdd above
thena\(\sup S\) exists in \(\mathbb{R}\)

這一條不證明，是整章的出發點。有理數 \(\mathbb{Q}\) 沒有這個性質：\(\{q \in \mathbb{Q} : q^2 \lt 2\}\) 在 \(\mathbb{Q}\) 裡沒有最小上界。

課本的寫法實數的每一個非空且有上界的子集，都有最小上界，而且這個最小上界是實數。
用到：D2
被用於：T1 T2 T6

意思是：比 \(u\) 小一點點的數都不再是上界。後面的證明幾乎都是用這個形式，而不是直接用 D2。

5.2 關聯心智圖

定義 Definition（D）公設 Axiom（A）定理 Theorem（T）輔助定理 Lemma（L）推論 Corollary（C）箭頭 A → B：證明 B 時用到 A。點方塊可跳到該條。

為了讓圖好讀，圖上只畫主要的依賴關係。完整的依賴列在每一條筆記底下的「用到」。

5.3 這張圖怎麼讀

  1. D1 → D2 → A1：先有上界，才能定義最小上界；有了最小上界這個名詞，才能敘述公設。
  2. D2 → L1：L1 只是把 D2 的條件 2 換一個說法：「比 \(u\) 小的數都不是上界」。
  3. A1、L1 → T1：反證法。假設 \(\mathbb{N}\) 有上界，A1 給出 \(u = \sup \mathbb{N}\)；L1 取 \(\varepsilon = 1\)，得到 \(m \in \mathbb{N}\) 滿足 \(u - 1 \lt m\)，於是 \(m + 1 \gt u\)，矛盾。
  4. T1 → C1：對 \(x = 1/\varepsilon\) 用 T1。
  5. A1、L1、D3、D4 → T2：A1 給出 \(u = \sup\{x_n\}\)。L1 給出某一項 \(x_N \gt u - \varepsilon\)；因為遞增（D4），之後每一項都落在 \(u - \varepsilon\) 和 \(u\) 之間，這正是 D3 的條件。
  6. T2 → T3：左端點 \((a_n)\) 遞增且有上界 \(b_1\)，用 T2 得到極限 \(\xi\)，再驗證 \(\xi\) 在每個區間裡。
  7. L2、T2 → T4：L2 抽出一個單調子數列；原數列有界，所以子數列也有界；T2 說它收斂。
  8. D5 → L3：取 \(\varepsilon = 1\)，第 \(N\) 項之後的每一項都和 \(x_N\) 相差不到 1。
  9. L3、T4、D5 → T5：Cauchy 數列有界（L3），所以有收斂子數列（T4）；再用 D5 說明整個數列都跟著子數列收斂到同一個極限。
  10. T4 → T6：先用 T4 證明 \(f\) 有界，A1 給出 \(M = \sup f\)；L1 取一列點 \(x_n\) 使 \(f(x_n) \to M\)，T4 抽出收斂子數列，極限點 \(c\) 就滿足 \(f(c) = M\)。
畫完圖可以看出：所有箭頭往上追，最後都回到紫色的 A1。這就是「公設」的意思，整章只有這一條是不證明的。三個黃色的輔助定理各自只服務一兩個定理：L1 是 A1 的好用版本，L2 為 T4 準備，L3 為 T5 準備。另外，圖最底下的 T6 就是微積分那一章沒有證明的 T1；兩章的圖在這裡接起來了。

6. 自己動手的步驟

  1. 選一章，照課本順序讀。遇到定義、公設、定理、輔助定理、推論就停下來。
  2. 把它抄成簡式：前提寫最上面，條件編 1、2、3，結果編 a、b、c，行首寫 if、&、or、then、iff。
  3. 給它一個代號（D1、T1…），並在旁邊寫「用到：…」。課本的證明第一段通常就會告訴你用到哪幾條。
  4. 一章抄完，把代號畫成關聯圖：A 用來證明 B，就畫 A → B。
  5. 蓋住筆記，看著圖默寫每一條：先寫骨架（幾個條件、幾個結果），再填內容。寫不出來的那一條就是還沒懂的地方。

抄寫看起來慢，但改寫成簡式時必須決定「哪些是條件、哪些是結果」，這個判斷本身就是在理解定理。
