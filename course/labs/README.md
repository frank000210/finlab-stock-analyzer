# 學習中心 Labs

每個單元一個資料夾，裡面有：

- `README.md`：實作步驟（學習中心的單元頁也會顯示）
- `check.py`：自動驗收腳本，只用 Python 標準函式庫
- 起始檔（部分單元）

## 使用方式

1. 在學習中心的單元頁按「下載 lab 起始檔」，或直接使用 repo 裡的 `course/labs/<單元>/`
2. 找一個**練習用的 git repo**（不要用正式專案），在裡面照 README 做
3. 在練習 repo 的根目錄執行驗收：

```bash
python path/to/check.py .
```

全部項目顯示 ✅ 就代表完成，回到單元頁勾選「我已完成這個 lab」。

`check.py` 只會**讀取**你的檔案（u6、l7 會用範例輸入執行你寫的 hook／狀態列腳本），不會修改任何東西。
