# L7 介面客製：狀態列與快捷鍵

> 本課目標：讓每天使用的介面更順手。這一課比較輕鬆，但做完之後你會每天看到成果。

## 狀態列（status line）

狀態列是 Claude Code 底部的一行，內容由**你寫的腳本**決定。Claude Code 會把 session 資料用 JSON 從 stdin 傳給腳本，腳本印出什麼就顯示什麼。

常見用途：

- 顯示目前的模型與 git 分支
- 顯示 context 用了多少百分比
- 顯示這個 session 的預估花費

### 最快的做法：/statusline

輸入 `/statusline`，用一句話描述你要什麼，例如：

```text
/statusline 顯示模型名稱、目前資料夾、git 分支和 context 使用百分比
```

Claude 會幫你寫好腳本並設定。

### 手動設定

在 `~/.claude/settings.json` 加上：

```json
{
  "statusLine": {
    "type": "command",
    "command": "python ~/.claude/statusline.py"
  }
}
```

腳本範例（`~/.claude/statusline.py`）：

```python
import json
import os
import subprocess
import sys

data = json.load(sys.stdin)
model = data.get("model", {}).get("display_name", "?")
folder = os.path.basename(data.get("workspace", {}).get("current_dir", ""))
pct = data.get("context_window", {}).get("used_percentage") or 0
cost = data.get("cost", {}).get("total_cost_usd") or 0

try:
    branch = subprocess.run(
        ["git", "branch", "--show-current"],
        capture_output=True, text=True, timeout=2,
    ).stdout.strip()
except Exception:
    branch = ""

print(f"[{model}] {folder}{' @ ' + branch if branch else ''} | context {pct:.0f}% | ${cost:.2f}")
```

### 可用的欄位（節錄）

| 欄位 | 內容 |
|---|---|
| `model.display_name` | 模型顯示名稱 |
| `workspace.current_dir` | 目前工作目錄 |
| `context_window.used_percentage` | context 使用百分比 |
| `cost.total_cost_usd` | 這個 session 的預估花費（美元，依牌價計算，可能和實際帳單不同） |

其他設定：`padding` 調整左右間距；`refreshInterval` 讓腳本每 N 秒重跑一次（例如要顯示時鐘）。

## 快捷鍵（keybindings）

輸入 `/keybindings` 會建立或開啟 `~/.claude/keybindings.json`。格式是依「情境（context）」分組的按鍵對應：

```json
{
  "$schema": "https://www.schemastore.org/claude-code-keybindings.json",
  "bindings": [
    {
      "context": "Chat",
      "bindings": {
        "ctrl+e": "chat:externalEditor",
        "meta+g": "command:compact"
      }
    }
  ]
}
```

- `chat:externalEditor`：用外部編輯器寫長提示詞
- `command:compact`：按鍵直接執行 `/compact`；`command:<名稱>` 可以綁任何斜線指令
- 把某個按鍵設成 `null` 可以解除預設綁定

存檔後立刻生效，不用重開。`Ctrl+C`、`Ctrl+D` 等少數按鍵是保留的，不能重新綁定。

幾個預設快捷鍵值得記住：

| 按鍵 | 動作 |
|---|---|
| Shift+Tab | 切換 permission mode |
| Ctrl+T | 顯示／隱藏 todo 清單 |
| Ctrl+O | 切換詳細的對話紀錄 |
| Ctrl+R | 搜尋輸入歷史 |
| Ctrl+B | 把目前的任務移到背景執行 |

## 本課小結

- 狀態列是一支讀 stdin JSON、印出一行文字的腳本；`/statusline` 可以讓 Claude 幫你寫
- 快捷鍵設定在 `~/.claude/keybindings.json`，依情境分組，`command:<名稱>` 可以綁斜線指令
