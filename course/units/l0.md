# L0 課前準備

> 本課目標：把 Claude Code 跑起來，認識它的介面與最基本的安全觀念。這一課不用寫任何設定，只要能開始對話就算完成。

## Claude Code 是什麼

Claude Code 是一個 **AI 代理（Agent）**。它跟聊天機器人最大的差別是：它不只回答，還會**動手做事**——讀你的檔案、改程式、跑指令、查網路，然後根據結果決定下一步。

這也代表一件事：**它操作的是你電腦上的真實檔案**。所以從第一天開始就要建立兩個習慣：

1. 在 git repo 裡工作，隨時可以用 `git diff` 看它改了什麼、用 `git restore` 退回
2. 看懂它每次要執行的指令再按允許（下一單元會教怎麼用權限規則減少確認次數）

## 安裝與啟動

Claude Code 有幾種介面，背後的 Agent 迴圈完全一樣，差別只在操作方式：

| 介面 | 適合 | 怎麼開始 |
|---|---|---|
| 終端機 CLI | 習慣命令列、要寫腳本自動化 | 安裝後在專案資料夾執行 `claude` |
| 桌面 App（Code 分頁） | 想要圖形介面、看 diff、開瀏覽器預覽 | 開啟 Claude 桌面 App，切到 Code |
| VS Code / JetBrains 擴充 | 邊寫程式邊用 | 從擴充市集安裝 |

安裝方式請照官方 Quickstart：<https://code.claude.com/docs/en/quickstart>。第一次啟動會要求登入 Claude 帳號（訂閱方案）或設定 API 金鑰（依用量計費）。

## 第一次對話

在一個你熟悉的專案資料夾裡啟動，然後試著問：

```text
這個專案在做什麼？主要的目錄各放什麼？
```

觀察它怎麼回答：它會先用搜尋與讀檔工具「蒐集資訊」，再整理成回答。這就是 U4 會拆解的 **Agent 迴圈**。

再試一個會動手的任務：

```text
幫我在 README 最後加一段「本機開發」說明，列出啟動指令
```

這次它會要求你允許編輯檔案。看清楚它要改的內容後再允許。

## 常用斜線指令

在輸入框打 `/` 會跳出指令清單。先記住這幾個：

| 指令 | 用途 |
|---|---|
| `/help` | 列出所有指令 |
| `/context` | 看目前 context 被哪些東西佔用（U1 會用到） |
| `/clear` | 清空對話、開新的 session |
| `/compact` | 把冗長對話壓縮成摘要，騰出空間 |
| `/init` | 自動幫專案產生一份 CLAUDE.md 草稿 |
| `/model` | 切換模型 |
| `/permissions` | 管理權限規則（U2） |
| `/hooks` | 瀏覽已設定的 hooks（U6） |
| `/mcp` | 看 MCP server 連線狀態（U2） |
| `/doctor` | 診斷安裝與設定問題 |

另外兩個鍵盤操作很重要：

- **Esc**：立刻打斷它目前的動作
- **Esc 連按兩下**：開啟 rewind，退回到之前的狀態（U4 詳細介紹）

## 計費與用量

- **訂閱方案**：在方案額度內使用，額度用完要等重置
- **API 金鑰**：依 token 用量計費

不管哪種，**context 越大越貴、也越慢**。這是整套課程反覆出現的主題：把對的資訊、在對的時間放進 context，就是客製化的核心。

## 本課小結

- Claude Code 是會動手的 Agent，操作的是真實檔案
- 在 git repo 裡工作，讓每個修改都看得到、退得回
- 熟悉 `/context`、`/clear`、`/compact`、Esc 這幾個基本操作
- 下一步：先做「程度檢測」，看看你該從哪個單元開始
